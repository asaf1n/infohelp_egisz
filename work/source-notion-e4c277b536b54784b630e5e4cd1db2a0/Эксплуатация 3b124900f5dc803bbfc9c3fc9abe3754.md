# Эксплуатация

## Контроль передачи в РЭМД

`Журналы` → `Протоколы ИБ`, колонка «Статус отправки» (`fir_emd_arc.status`)

| **Код** | **Статус** | **Содержание** |
| --- | --- | --- |
| `0` | Подготовлен | Протокол подписан, документ ожидает обработки |
| `1` | Сформирован запрос | Документ подготовлен к передаче |
| `2` | Получен синхронный ответ | Документ принят шлюзом РЭМД. Ожидается асинхронная проверка, срок ожидания до 24 часов |
| `3` | Ошибка внутреннего контроля | Документ не прошёл контроли на этапе формирования. Передача не выполнялась. Текст ошибки отображается в журнале |
| `4` | Успешный асинхронный ответ | Документ зарегистрирован в РЭМД, присвоен регистрационный номер |
| `5` | Ошибка в асинхронном ответе | Документ не прошёл проверки на стороне ЕГИСЗ. Текст ошибки отображается в журнале |

## Контроль передачи в ИЭМК

`Журналы` → `Протоколы ИБ`, колонки «Дата размещения СЭМД на фед. портале» и «Причина неразмещения во внеш. ИС».

## Переотправка документов

| **Контур** | **Действие** |
| --- | --- |
| РЭМД | `Журналы` → `Протоколы ИБ` → `Сервис` → `Переотправить в РЭМД` |
| ИЭМК | `Журналы` → `Протоколы ИБ` → `Сервис` → `Переотправить в ИЭМК` |

Автоматическая повторная передача документов с временными ошибками выполняется задачей службы репликации «Переотправка документов с ошибками».

## Отказ пациента от передачи данных

`Картотека пациентов` → `Карточка регистрации` → `Передача ПД`

Выбирается сервис, тип документа и признак отказа от передачи. Документы по пациентам с установленным признаком остаются в медицинской организации.

## Поддержание данных в актуальном состоянии

- Актуализация сведений о медицинской организации и подразделениях в ФРМО.
- Актуализация сведений о медицинских работниках в ФРМР при изменении кадрового состава, должностей и мест работы.
- Контроль сроков действия сертификатов УКЭП врачей.
- Актуализация справочников НСИ.

## Часто задаваемые вопросы

- Доступ к веб-интерфейсу РЭМД
    
    Доступ предоставляется по заявке в службу технической поддержки ЕГИСЗ. Авторизация выполняется через ЕСИА.
    
- Действия при ошибке «Документ с идентификатором уже зарегистрирован»
    
    Зарегистрированный документ сохраняется в РЭМД в неизменном виде. Для внесения исправлений в медицинской организации создаётся новый протокол, который передаётся на регистрацию как отдельный документ.
    
- Регистрация документов по анонимным пациентам
    
    РЭМД не принимает к регистрации документы без обязательной персональной информации о пациенте. Состав обязательных сведений установлен руководством по реализации вида СЭМД.
    
- Приём документов с подписью на основании машиночитаемой доверенности
    
    Регистрация документов, подписанных с применением машиночитаемой доверенности, на текущий момент не выполняется.
