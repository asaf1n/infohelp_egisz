# Тестирование

## Чек-лист проверки настроек

Настройки проверяются на филиалах подписания протоколов и на центральной базе данных.

| **Проверка** | **Путь в МИС и содержание проверки** |
| --- | --- |
| Версия МИС | Установлена текущая поддерживаемая версия с последними обновлениями |
| Подключение к порталу через OpenVPN ГОСТ | Проверка подключения к сервису данных виртуального сайта в личном кабинете [admin.infoclinica.ru](http://admin.infoclinica.ru) завершается успешно. На ПК со службой репликации открывается [ips.infoclinica.ru](http://ips.infoclinica.ru) с ответом EGISZ IPS proxy service |
| Служба SyncServer | Служба работает, справочники добавлены в файл конфигурации по составу из руководства по реализации конкретного СЭМД |
| Адрес callback-сервиса | `Сервис` → `Настройки` → `Интеграция`. Заполнен по формату `http://gost-[идентификатор клиники].infoclinica.lan:9945` |
| Код РМИС и UUID | `Сервис` → `Настройки` → `Интеграция`. Значения соответствуют приведённым в разделе параметров интеграции |
| Настройки ЭЦП | `Сервис` → `Подключение оборудования` → `ЭЦП`. Заполнены криптопровайдер и параметры проверки ЭЦП |
| Медиа-база | `Справочники` → `Структура организации` → `Филиалы`. База настроена и добавлена в поле «БД подписанных протоколов (медиа-база)» |
| Временная зона | `Справочники` → `Структура организации` → `Филиалы`. Часовой пояс указан по UTC, например Москва +3 |
| Связь с физическим лицом и СНИЛС врача | `Справочники` → `Справочник персонала`. Для врача указано физическое лицо с заполненным СНИЛС. СНИЛС из подписи используется для идентификации врача в ФРМР |
| Должность врача | Поле «Должность (справочник)» заполнено значением из справочника НСИ и соответствует должности врача в ФРМР |
| Сертификат ЭЦП | На вкладке «Сертификаты ЭЦП» добавлен действующий сертификат УКЭП врача |
| Федеральный код подразделения (OID) | `Справочники` → `Структура организации` → `Подразделения`. Для подразделения, в котором выписан документ, заполнено поле «Федеральный код подразделения МО (OID)» по справочнику ФНСИ 1.2.643.5.1.13.13.99.2.114. Значение отличается от OID юридического лица и соответствует данным ФРМО |
| Федеральное наименование подразделения МО | Для подразделения, в котором выписан документ, заполнено поле «Федеральное наименование подразделения МО» по тому же справочнику |

При ошибках в любом из пунктов или при сохранении проблемы создаётся обращение на портале технической поддержки [support.sdsys.ru](https://support.sdsys.ru). В обращении указываются пациент, врач, идентификатор и дата протокола ИБ, текущий статус документа в журнале протоколов ИБ и текст ошибки из колонки «Причина неотправки во внеш. системы».

## Проверочный запрос

Запрос выполняется на базе данных, в которой подписываются документы. Результат каждой позиции принимает значение «ОК».

#### SQL

```sql
-- 1. Проверка адреса callback сервиса
SELECT
    'Адрес callback сервиса' AS CHECK_NAME,
    iif(coalesce(keyvalue,'') = '', 'В настройках не заполнен', 'ОК') AS CHECK_RESULT
FROM m_config WHERE keyname = 'FIR_EMD_CALLBACK'

UNION ALL

-- 2. Проверка ОГРН юридического лица
SELECT
    'ОГРН юридического лица' AS CHECK_NAME,
    iif(coalesce(j.ogrn, '') = '', 'Не заполнен', iif(char_length(j.ogrn) <> 13, 'Заполнен некорректно (кроме ИП - 15 символов)', 'ОК'))
FROM jpersons j
JOIN filials f ON f.jid = j.jid
WHERE f.filid = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))

UNION ALL

-- 3. Проверка юридического адреса
SELECT
    'Юридический адрес' AS CHECK_NAME,
    iif(coalesce(jpau.klcode, '') = '', 'Не указан', 'ОК')
FROM jpersons j
JOIN filials f ON f.jid = j.jid
LEFT JOIN jpaddress jpau ON j.jid = jpau.recid AND jpau.addrtype = 1
WHERE f.filid = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))

UNION ALL

-- 4. Проверка фактического адреса
SELECT
    'Фактический адрес' AS CHECK_NAME,
    iif(coalesce(jpaf.klcode, '') = '', 'Не указан', 'ОК')
FROM jpersons j
JOIN filials f ON f.jid = j.jid
LEFT JOIN jpaddress jpaf ON j.jid = jpaf.recid AND jpaf.addrtype = 0
WHERE f.filid = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))

UNION ALL

-- 5. Проверка телефона организации
SELECT
    'Телефон организации' AS CHECK_NAME,
    iif(coalesce(jpau.phonetext, '') = '', 'Не указан', 'ОК')
FROM jpersons j
JOIN filials f ON f.jid = j.jid
LEFT JOIN jpaddress jpau ON j.jid = jpau.recid AND jpau.addrtype = 1
WHERE f.filid = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))

UNION ALL

-- 6. Проверка OID юридического лица
SELECT
    'OID юридического лица' AS CHECK_NAME,
    iif(coalesce(j.fir_oid,'') = '', 'Не указан', 'ОК')
FROM jpersons j
JOIN filials f ON f.jid = j.jid
WHERE f.filid = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))

UNION ALL

-- 7. Проверка кода территории юридического лица
SELECT
    'Код территории юр. лица' AS CHECK_NAME,
    iif(coalesce(j.kodter,'') = '', 'Не указана', 'ОК')
FROM jpersons j
JOIN filials f ON f.jid = j.jid
WHERE f.filid = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))

UNION ALL

-- 8. Проверка лицензии юридического лица
SELECT
    'Лицензия юридического лица' AS CHECK_NAME,
    iif(coalesce(j.licnumber,'') = '', 'Не указаны сведения', 'ОК')
FROM jpersons j
JOIN filials f ON f.jid = j.jid
WHERE f.filid = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))

UNION ALL

-- 9. Проверка временной зоны филиала
SELECT
    'Временная зона филиала' AS CHECK_NAME,
    iif(f.timezone = 0, 'Установлено значение по умолчанию (0)', 'ОК')
FROM filials f
WHERE f.filid = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))

UNION ALL

-- 10. Проверка OID подразделений
SELECT
    'OID подразделения в ФРМО (' || trim(csh.cashname) || ')' AS CHECK_NAME,
    iif(coalesce(csh.fir_oid,'') = '', 'Не указан', 'ОК')
FROM cashref csh
WHERE csh.filial = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))

UNION ALL

-- 11. Проверка наименования подразделений для РЭМД
SELECT
    'Наименование подразделения в ФРМО (' || trim(csh.cashname) || ')' AS CHECK_NAME,
    iif(coalesce(csh.fir_name,'') = '', 'Не указано', 'ОК')
FROM cashref csh
WHERE csh.filial = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))

UNION ALL

-- 12. Проверка наличия триггеров
SELECT
    'Наличие триггеров РЭМД' AS CHECK_NAME,
    iif(exists(select RDB$TRIGGER_NAME from RDB$TRIGGERS where RDB$TRIGGER_NAME containing 'FIR_EMD_TREATPLACESIGN' and upper(RDB$RELATION_NAME) = upper('TREATPLACESIGNDET')), 'OK', 'Отсутствуют')
FROM RDB$DATABASE

UNION ALL

-- 13. Проверка записи о БД для интеграции с РЭМД
SELECT
    'Запись о БД интеграции' AS CHECK_NAME,
    iif(exists(select * from filial_base where grpid = 9924 and basetype = 1), 'OK', 'Отсутствует')
FROM RDB$DATABASE

UNION ALL

-- 14. Проверка записи о медиа БД для интеграции с РЭМД
SELECT
    'Запись о медиа БД интеграции' AS CHECK_NAME,
    iif(exists(select * from filial_base where grpid = 9924 and basetype = 2), 'OK', 'Отсутствует')
FROM RDB$DATABASE

UNION ALL

-- 15. Сопоставление услуг с номенклатурой Минздрава
SELECT
    'Код услуги по НСИ Минздрава' AS CHECK_NAME,
    iif(exists(select * from wschema w where coalesce(w.officialcodeid, 0) > 0), 'ОК', 'Не заполнен ни для одной услуги')
FROM RDB$DATABASE

UNION ALL

-- 16. Список медицинских специализаций отделения
SELECT
    'Специализации отделения (' || trim(d.depname) || ')' AS CHECK_NAME,
    iif(coalesce(d.idmsplist, '') = '', 'Не указаны', 'ОК')
FROM departments d
WHERE d.filial = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))
  AND (d.disdate is null or d.disdate > current_date)

UNION ALL

-- 17. Действующий сертификат УКЭП сотрудника
SELECT
    'Сертификат УКЭП (' || trim(doc.fullname) || ')' AS CHECK_NAME,
    iif(exists(select * from certdoctor cd
               join certificate c on c.certid = cd.certid
               where cd.dcode = doc.dcode
                 and c.certtype = 1
                 and c.certstate = 3
                 and (c.validto is null or c.validto >= current_date)), 'ОК', 'Действующий сертификат отсутствует')
FROM doctor doc
WHERE doc.filial = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))
  AND coalesce(doc.locked, 0) <> 1
  AND coalesce(doc.snils, '') <> ''

UNION ALL

-- 18. Специальность в отделении у подписывающих сотрудников
SELECT
    'Специальность в отделении (' || trim(doc.fullname) || ')' AS CHECK_NAME,
    iif(exists(select * from doctdepartlinks ddl
               where ddl.dcode = doc.dcode
                 and coalesce(ddl.idmsp, 0) > 0
                 and (ddl.bdate is null or ddl.bdate <= current_date)
                 and (ddl.fdate is null or ddl.fdate >= current_date)), 'ОК', 'Не указана')
FROM doctor doc
WHERE doc.filial = (SELECT keyvalue FROM m_config WHERE upper(keyname) = upper('filial'))
  AND coalesce(doc.locked, 0) <> 1
  AND exists(select * from certdoctor cd
             join certificate c on c.certid = cd.certid
             where cd.dcode = doc.dcode
               and c.certtype = 1
               and c.certstate = 3
               and (c.validto is null or c.validto >= current_date));
```

Проверка 15 подтверждает наличие заполненных кодов Минздрава в прейскуранте. Состав услуг, требующих кода, определяется перечнем услуг, оказываемых медицинской организацией.

Проверки 17 и 18 охватывают действующих сотрудников: проверка 17 отбирает сотрудников с заполненным СНИЛС, проверка 18 — сотрудников с действующим сертификатом УКЭП.

## Тестовая передача

1. Обучение сотрудников: подписание протокола, просмотр статусов в журнале протоколов ИБ, оформление отказа пациента от передачи данных.
2. Передача тестового документа по каждому подключённому виду СЭМД.
3. Анализ и устранение ошибок: реквизиты, состав подписей, структура документа.
4. Повторное выполнение проверочного запроса.

## Ввод в эксплуатацию

1. Запуск передачи документов в штатном режиме.
2. Усиленный контроль статусов в течение 3 рабочих дней после запуска.
3. Переход на стандартную линию технической поддержки.
