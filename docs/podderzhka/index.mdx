# Регламент технической поддержки

Обращения регистрируются на [портале технической поддержки СДС](https://support.sdsys.ru/). Для проблемы интеграции с ЕГИСЗ подготовьте сведения по [инструкции обращения в поддержку](/trunk/egisz/diagnostics/support-request).

Ответственные, каналы связи, сроки реакции и решения определяются условиями сопровождения МО. Общий регламент для всех модулей МИС в этой справке не приведён.
