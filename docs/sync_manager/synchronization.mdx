# Загрузка и обработка справочников

До выполнения проверьте [настройки источника](./settings.mdx), целевую БД и требуемый список кодов. Для ЕГИСЗ используйте [перечень НСИ для подключаемых СЭМД](../egisz/settings/nsi.mdx).

## Запуск менеджера

Процедуру выполняет специалист, имеющий доступ к целевой БД и настройке справочников. Для автоматической работы дополнительно настраивается [служба SyncServer](./automation.mdx).

1. В каталоге установки МИС, например `\Infoclinica`, откройте `IStart.exe` и выберите нужное подключение в окне **Базы данных**.
2. В правой части окна откройте **Корпоративные утилиты → Синхронизация НСИ**. Пункт с пометкой **Только для сотрудников SDS** предназначен для сотрудников сопровождения; если он недоступен, запуск организует специалист сопровождения.
3. Проверьте БД в открытом менеджере и затем в поле **Целевая** мастера. При несовпадении с заданием уточните подключение до выполнения загрузки.

[![Выбор базы и запуск Синхронизации НСИ из корпоративных утилит](/img/sync-manager/launcher.png)](/img/sync-manager/launcher.png)

Пункт **SyncServer as App** в окне запуска запускает сервер с `-app -debug`. Для ручной работы со справочниками выбирайте **Синхронизация НСИ**. Диагностический запуск сервера описан отдельно в [автоматической синхронизации](./automation.mdx#application-mode).

## Загрузка

1. Откройте **Справочники → Мастер синхронизации**.
2. Выберите **Загрузка справочников в базу данных** и нажмите **Далее**.
3. Для ФНСИ отметьте **Федеральный портал Росминздрав (API)** и нажмите **Далее**. Адрес и ключ проверьте в **Сервис → Настройки → Федеральный портал НСИ**.
4. Отметьте нужные справочники. Поиск работает по наименованию и OID; для [комплекта СЭМД](../egisz/semd/profiles.mdx) сверьте каждый код с утверждённым составом.
5. В поле **Директория для загрузки файлов** укажите доступный каталог, например `\Infoclinica\Services\Sync\sync_temp`, либо включите **Использовать директорию по умолчанию из настроек справочника**. Для обычного получения обновлений оставьте **Использовать предварительно скачанные файлы для загрузки** выключенным.
6. На итоговом экране сверьте **Исходная**, **Целевая**, **Режим** и список справочников, затем нажмите **Выполнить**. Дождитесь окончания операции и сохраните её результат.
7. В **Справочники → Настройка справочников** откройте выбранный справочник. Проверьте появление загруженной версии и строк в нижней части формы. При отсутствии результата перейдите к [диагностике](./check.mdx#downloaded-not-visible).

:::note Как читать экран выполнения
На снимке выбран справочник **Виды нозологических единиц диагноза**, OID `1.2.643.5.1.13.13.11.1077`. Видны сообщение **Перед получением версии справочника** и недоступные кнопки. Этот экран не подтверждает завершение загрузки; проверьте её результат перед обработкой.
:::

## Обработка

1. Снова откройте мастер и выберите **Обработка справочников**.
2. Выберите источник и справочники.
3. В списке загруженных, но необработанных версий отметьте необходимые записи.
4. На итоговом экране проверьте выбор и нажмите **Выполнить**.
5. Проверьте версию в настройках справочника и доступность контрольного значения в МИС. Полный порядок приведён в [проверке результата](./check.mdx).

Если версия отсутствует в списке необработанных, проверьте выбранную БД, источник, наличие загрузки и результат предыдущей обработки.

## Завершение

Работа завершена, когда требуемая версия загружена, её обработка подтверждена и контрольное значение доступно в нужном поле МИС. Сохраните код, версию, БД, время выполнения и результат. Для филиальной сети дополнительно проверяется распространение данных из ЦБД.

В мастере также есть режим **Проверка справочников**. Для него используйте критерии документации установленной версии и дополнительно проверяйте доступность значений в МИС.

Для файловых источников размещение обработанных файлов зависит от **Режима перемещения обработанных файлов**. Проверьте каталоги `Archive` и `Error`, а также журнал: ошибки доступа к файлам могут быть отражены только в журнале.
