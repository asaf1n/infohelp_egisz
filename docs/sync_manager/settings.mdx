# Настройки справочников и профилей

## Источники

Откройте **Сервис → Настройки**. Для федерального портала НСИ укажите адрес `https://nsi.rosminzdrav.ru` и ключ авторизации. Для другого источника используйте его реквизиты подключения. Ключи и пароли не включайте в снимки экрана и протоколы проверки.

Группы FHIR, РЛС Аврора, ФИАС и ГАР имеют собственные настройки. Для ГАР требуются отдельная БД и подготовленные каталоги полной версии или изменений. Их подробное описание доступно в [настройках модуля](https://help.infoclinica.ru/26.1/sync_manager/sync_manager_settings/).

## Справочники

В **Справочники → Настройка справочников** найдите нужную запись и проверьте:

- тип источника, код, параметры доступа и признак **Не используется**;
- директорию, маску файла и формат для файловой загрузки;
- поле **Текущая версия** и список загруженных версий внизу формы;
- поле **Обработчик**, если после загрузки требуется обработка;
- режим перемещения обработанных файлов.

Поле **Таблица** показывает имя таблицы загрузки справочника, а поле **Обработчик** задаёт процедуру обработки. Проверьте эти поля, если справочник загружен, но его значения не появились в МИС.

Пример настроек справочника **Сведения о наиболее вероятном пути передачи**: код `1.2.643.5.1.13.13.99.2.859`, таблица `NSI_ROUTEINFECTION`, текущая версия `2.1`. Внизу показаны строки версии `2.1 от 25.11.2021`. Требуемую версию определяйте по условиям интеграции. Поле **Обработчик** проверьте в самой форме: на иллюстрации оно не показано.

[![Настройки справочника: код, таблица NSI_ROUTEINFECTION, версия и загруженные строки](/img/sync-manager/reference.png)](/img/sync-manager/reference.png)

Кнопка **Загрузка** открывает менеджер в режиме загрузки, **Обработка** открывает менеджер в режиме обработки. Для пользовательского справочника поведение кнопки загрузки отличается и описано в [справочнике параметров](https://help.infoclinica.ru/26.1/sync_manager/sync_manager_handbooks/). После изменения параметров нажмите **Сохранить**.

## Каталоги

| Назначение | Где задаётся | Проверка |
|---|---|---|
| Каталог выбранного ручного запуска | **Директория для загрузки файлов** в мастере | Например, `\Infoclinica\Services\Sync\sync_temp` |
| Каталог справочника или группы | **Директория по умолчанию** в настройках | Используется мастером при включённом флаге **Использовать директорию по умолчанию из настроек справочника** |
| Каталог журнала службы | `logpath` в `sync.conf` | Например, `\Infoclinica\Services\Sync\log` |

`logpath` определяет размещение журнала. Каталог файлов НСИ задаётся отдельно. В шаблоне `sync.conf` указанного компонента отдельного параметра каталога загрузки нет; фактическое использование каталогов службой проверьте на контрольном справочнике.

Настройки шаблонов, преобразования XSLT и последовательной загрузки SAX применяют по спецификации конкретного справочника. Все параметры и доступные варианты приведены в [справочнике параметров формы](https://help.infoclinica.ru/26.1/sync_manager/sync_manager_handbooks/).

## Профили

Профиль объединяет справочники для совместной загрузки. Выбор готового набора, назначение реквизитов, настройка `syncprofiles` и проверка состава описаны на странице [«Профили НСИ для СЭМД»](../egisz/semd/profiles.mdx).
