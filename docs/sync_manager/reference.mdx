# Справочник параметров sync.conf

## Параметры {#configuration}

| Параметр | Назначение | Что указать и проверить |
|---|---|---|
| `a` | Псевдоним подключения к БД | Имя секции `infodent.ini`, например `dentbase` |
| `uid` | Идентификатор пользователя службы в МИС | Идентификатор пользователя с нужными правами в выбранной БД |
| `logpath` | Каталог журнала службы | Например, `\Infoclinica\Services\Sync\log`; учётной записи Windows службы нужны права записи |
| `syncrefcode` | Список идентификаторов справочников через запятую | OID выбранных справочников |
| `syncprofiles` | Список идентификаторов профилей через запятую | Коды выбранных [профилей загрузки](../egisz/semd/profiles.mdx) |
| `syncinterval` | Интервал между циклами, в секундах | Например, `3600` для одного часа; учитывается при незаданном `SyncTime` |
| `SyncTime` | Время синхронизации в формате `ЧЧ:ММ` | Например, `01:00`; при заданном времени `syncinterval` игнорируется |

Учётной записи Windows, указанной на вкладке **Вход в систему** свойств службы, нужны права на запись в папку службы.

## Расписание

Выберите один способ задания времени:

- **По времени:** заполните `SyncTime`, например `01:00`. `syncinterval` при этом игнорируется.
- **По интервалу:** оставьте `SyncTime` пустым и задайте число секунд в `syncinterval`. Например, `3600` соответствует одному часу, `86400` соответствует 24 часам.

Если задан `SyncTime`, запись **Интервал синхронизации, сек:0** в журнале оценивайте вместе с временем запуска в конфигурации.

Порядок применения параметров при настройке службы описан в [автоматической синхронизации](./automation.mdx#configuration-steps).
