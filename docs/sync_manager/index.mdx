# Модуль «Менеджер Загрузок»

Модуль загружает внешние справочники в БД и выполняет предусмотренную для них обработку. Для ручной работы используется SyncManager, для фоновой синхронизации служит SyncServer. Пункт запуска менеджера в интерфейсе называется **Синхронизация НСИ**.

Выберите целевую БД и состав НСИ, загрузите нужные версии справочников, выполните обработку и проверьте, что значения доступны в нужных полях МИС.

| Задача | Инструкция |
|---|---|
| Настроить источник и справочники | [Настройки справочников и профилей](./settings.mdx) |
| Выбрать профиль загрузки НСИ для СЭМД | [Профили НСИ для СЭМД](../egisz/semd/profiles.mdx) |
| Загрузить справочники вручную | [Загрузка и обработка справочников](./synchronization.mdx) |
| Настроить загрузку по расписанию | [Автоматическая синхронизация](./automation.mdx) |
| Проверить результат или разобрать ошибку | [Проверка службы синхронизации и НСИ](./check.mdx) |

## Применимость

Описание интерфейса относится к справке МИС 26.1. Примеры настройки SyncServer приведены для компонента `26.4.3.1` (`trunk-r118645`). Совместимость всех процедур с выпуском 26.1 не подтверждена; перед настройкой сверьте версию компонента и комплект поставки.

Параметры службы **Infoclinica SyncServer**, расписание и журналы описаны в [автоматической синхронизации](./automation.mdx). Параметры командной строки SyncManager и файла `sync.conf` имеют разное назначение.

Для ЕГИСЗ состав справочников и сопоставление услуг определяются [требованиями НСИ](../egisz/settings/nsi.mdx).
