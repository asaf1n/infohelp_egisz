# Система репликации

Система выполняет задачи обмена и обработки по заданной конфигурации.

| Компонент | Назначение |
|---|---|
| ReplServer | Выполняет задачи; работает как служба Windows или демон Linux |
| ReplConf | Настройка репликации и доступ к консоли управления сервером |
| База конфигурации репликатора | Хранит настройки отдельно от баз МИС |

В типовой филиальной сети сервер располагается на верхнем уровне. Несколько экземпляров требуют отдельной схемы распределения задач и тщательной настройки.

## Порядок работы

1. [Установите и настройте репликатор](./setup.mdx).
2. [Проверьте задачи и группы](./configuration.mdx).
3. Выполните [проверку службы и результатов](./check.mdx).

Для ЕГИСЗ дополнительно используйте [перечень задач ИЭМК и РЭМД](../../egisz/settings/replication.mdx). Общий журнал репликации описывает задачи типа `repl`; другие типы требуют соответствующих журналов и проверки результата в МИС.

:::note Применимость
До развёртывания подтвердите состав и параметры компонента у ответственного за его сопровождение. Порядок установки и работы задач проверьте на тестовом контуре.
:::
