# Установка и настройка репликатора

До установки определите сервер, поддерживаемую версию репликатора, разрядность, базы МИС и схему филиальной сети. Получите эталонную базу конфигурации, соответствующую поставке.

## Последовательность

1. Разместите согласованный комплект репликатора на выделенном сервере.
2. Разверните эталонную БД конфигурации. Перед изменением существующей конфигурации сохраните её резервную копию.
3. Через ReplConf сверьте базы, группы и задачи с принятой схемой обмена. См. [проверку конфигурации](./configuration.mdx). Если база конфигурации клиники создана на основании эталонной, актуализируйте справочник таблиц по [эталонной базе replconf](./configuration.mdx#обновление-справочника-таблиц-по-эталонной-базе-replconf).
4. Для Windows зарегистрируйте выбранный исполняемый файл ReplServer параметром `/install`, если служба ещё не установлена. Для соответствующей разрядности используются `replserver32.exe` и `replserver64.exe`; имя и совместимость сверьте с комплектом поставки.
5. Проверьте параметры установленной службы средствами ОС: путь к файлу, учётную запись и режим запуска. Подключитесь к серверу через консоль ReplConf и выполните [проверку работы](./check.mdx).

## Условия самостоятельной установки

Получите описание параметров запуска и подключения к БД конфигурации, административного порта, журналирования, прав служебной учётной записи и порядка обновления службы для используемой поставки. Без этих сведений приведённой последовательности недостаточно для самостоятельного развёртывания. Для Linux используйте отдельную инструкцию установки и управления демоном.
