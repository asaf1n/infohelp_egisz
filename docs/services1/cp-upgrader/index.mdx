# Система обновлений

Обновление МИС включает размещение файлов приложений и библиотек, затем изменение баз данных через `Upgrader.exe`. Этот раздел описывает работу с базами данных. Дистрибутив и порядок перехода между версиями предоставляет поставщик МИС.

## Подготовка

1. Зафиксируйте текущую и целевую версии МИС, ревизию обновлений и перечень баз, включая филиалы.
2. Получите соответствующий комплект приложений и `Upgrade.zip`. Для установки исправлений используйте комплект текущей версии; переход на другую версию выполняйте по согласованному маршруту обновления.
3. Согласуйте время работ и порядок восстановления. Вход в систему обновлений требует пользователя с типом конфигурации **Администратор**.
4. В BkUtils откройте **Сервис → Резервное копирование → Копирование** и создайте копию каждой целевой БД. Зафиксируйте расположение и результат резервирования.
5. Для крупного обновления или сети филиалов сначала выполните пробное обновление копий БД. В BkUtils для подготовки копий предусмотрена вкладка **Клонирование**.

Установленные изменения не отменяются кнопкой в мастере. Восстановление выполняют из резервной копии через вкладку **Восстановление**. Перед возвратом рабочей базы необходимо учитывать данные, появившиеся после создания копии.

## Выбор режима

| Режим | Когда применять |
|---|---|
| [Базовый](./basic.mdx) | Обычная установка исправлений или согласованный переход на следующую версию; источником служит `Upgrade.zip` |
| [Расширенный, Pro](./pro.mdx) | Требуется выбрать источник или выполнить специальный сценарий обновления |
| [Пользовательский](./user.mdx) | Организация сопровождает собственный набор обновлений |

После выполнения проверьте [журнал и работоспособность МИС](./check.mdx).
