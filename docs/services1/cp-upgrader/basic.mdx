# Базовый режим обновления

До запуска выполните [подготовку и резервное копирование](./index.mdx).

1. В окне выбора БД и запуска модулей выберите базу и откройте **Систему обновлений** (`Upgrader.exe`). Название пункта может отличаться в настройках клиники.
2. Выполните вход и отметьте целевые базы. Сверьте список с протоколом работ.
3. Выберите **Установка исправлений**, если сохраняется текущая версия БД. Для согласованного перехода выберите **Обновление до стабильной версии** и проверьте показанную целевую версию.
4. Нажмите **Выполнить**. При выборе нескольких баз мастер обрабатывает их последовательно.
5. Откройте **Журнал** и выполните [проверку результата](./check.mdx) для каждой базы. Завершите мастер кнопкой **Выход**.

Источник обновлений в этом режиме фиксирован: `Upgrade.zip`. Для другого источника используется [Pro](./pro.mdx).

## Если выполнение прервалось

Нажмите **Прервать**, сохраните идентификатор базы, код обновления и полный текст ошибки. Определите порядок восстановления с ответственным за обновление. Уже выполненные скрипты могли изменить базу.

Не используйте пропуск ошибки как подтверждение успешного обновления. **Отложить** оставляет скрипт для следующей попытки, такое событие не записывается в журнал. **Больше не выполнять** исключает дальнейшие попытки и сохраняет запись об ошибке. **Повторить** выполняет скрипт снова после устранения причины; решение принимает специалист, ведущий обновление.
