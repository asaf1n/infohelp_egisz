# Расширенный режим обновления

Pro запускается параметром `/p` у `Upgrader.exe`. После выбора БД откройте **Менеджер обновлений → Обновить БД**. Требования к копированию и версиям приведены в [подготовке](./index.mdx).

## Режимы мастера

| Режим | Результат |
|---|---|
| Полное обновление | Выполнение применимых обновлений из выбранного источника |
| Модульное обновление | Ограничение выбранными модулями |
| Выборочное обновление | Применение выбранного набора обновлений |
| Синхронизация обновлений | Перенос обновлений в целевую БД без исполнения скриптов; для применения нужен отдельный запуск |

Модульный и выборочный режимы требуют проверки зависимостей специалистом. Завершение синхронизации ещё не означает обновление структуры БД.

## Порядок работы

1. Выберите режим согласно плану работ.
2. Проверьте параметры доступа. Монопольный режим отключает пользователей и блокирует новые подключения; для версии МИС 26.1 указано требование Firebird не ниже 3.0.4. До работ подтвердите совместимость с используемым комплектом.
3. Выберите источник: `Upgrade.zip` либо БД, в которую предварительно загружены нужные обновления.
4. Выберите целевые базы и версию. Выполните обновление и [проверьте каждую базу](./check.mdx).

## Ошибки

Параметры **Пропускать все ошибки при выполнении** и **Игнорировать все ошибки** могут оставить базы обновлёнными частично. Их не включают в обычную процедуру обновления клиники.

В Pro доступны отключение от базы, переподключение с повтором и отключение пользователей с повтором. Эти действия меняют подключения и могут прервать работу пользователей; выбор действия должен соответствовать установленной причине ошибки.

Из менеджера доступны журнал обновлений, журнал ревизий, справочники версий и условий. Параметры справочников описаны в [разделе Pro справки МИС 26.1](https://help.infoclinica.ru/26.1/services1/cp-upgrader/cp-db_upgrade-pro/).
