# Пользовательские обновления

Пользовательский режим предназначен для собственных обновлений организации. Они хранятся отдельно от стандартных обновлений поставщика и не включаются автоматически в `Upgrade.zip`.

Для режима используются параметры `/p /u` и именованные пространства через `workspace`. Пространство `u` использует объекты с префиксом `U_`, включая `U_UPGRADE` и `U_UPGRADELOG`. Перед применением требуется проверенный порядок подготовки БД и репликации этих объектов.

## Подготовка пакета

1. Подготовьте и проверьте скрипты на копии БД.
2. В менеджере добавьте скрипты вручную, из файла либо буфера обмена; укажите версию и модуль.
3. Проверьте способ разбиения импортируемого текста: отдельные обновления, блоки или одно обновление.
4. Кнопкой **Применить** включите подготовленные обновления в ревизию. Скрипт вне ревизии ещё не готов к установке через этот механизм.
5. Передайте пакет через **Выгрузка** либо используйте подготовленную БД как источник в [Pro](./pro.mdx).
6. Выполните установку по согласованной схеме и [проверьте результат](./check.mdx).

:::note Подготовка комплекта
До первоначального развёртывания подтвердите имя исполняемого файла, состав объектов БД и скрипты создания триггеров для используемой поставки. Эта процедура описывает работу с пакетами после подготовки БД.
:::
