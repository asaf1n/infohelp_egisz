# Служебные модули

Инструкции предназначены для специалистов внедрения, сопровождения и администраторов медицинской организации.

| Задача | Инструкция |
|---|---|
| Подготовить и выполнить обновление МИС | [Система обновлений](./cp-upgrader/index.mdx) |
| Проверить установленное обновление | [Проверка результата обновления](./cp-upgrader/check.mdx) |
| Настроить обмен между базами данных | [Система репликации](./replic/index.mdx) |
| Проверить службу и выполнение задач | [Проверка работы репликатора](./replic/check.mdx) |
| Загрузить и обработать справочники | [Модуль «Менеджер Загрузок»](../sync_manager/index.mdx) |
| Проверить автоматическую синхронизацию | [Проверка службы синхронизации и НСИ](../sync_manager/check.mdx) |

Состав задач ИЭМК и РЭМД приведён в [настройке репликации ЕГИСЗ](../egisz/settings/replication.mdx), требования к справочникам описаны в [настройке НСИ](../egisz/settings/nsi.mdx).

Описание интерфейса относится к версии МИС 26.1. До работ в рабочей среде проверьте применимость процедур и контрольные сценарии на тестовой БД вашей версии МИС.
