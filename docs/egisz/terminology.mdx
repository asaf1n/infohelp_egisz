# Термины и сокращения

| Термин | Значение |
|---|---|
| ЕГИСЗ | Единая государственная информационная система в сфере здравоохранения |
| ИЭМК | Интегрированная электронная медицинская карта, подсистема ЕГИСЗ |
| ГИП | Главный индекс пациентов, компонент ИЭМК, содержащий демографические сведения о пациенте и его идентификаторы в информационных системах |
| РЭМД | Реестр электронных медицинских документов, подсистема ЕГИСЗ |
| ЭМД | Электронный медицинский документ |
| СЭМД | Структурированный электронный медицинский документ |
| УКЭП | Усиленная квалифицированная электронная подпись |
| ФРМО | Федеральный реестр медицинских организаций |
| ФРМР | Федеральный регистр медицинских работников |
| НСИ, ФНСИ | Нормативно-справочная информация; федеральная система НСИ Минздрава |
| OID | Объектный идентификатор. В руководстве используются OID организации, OID подразделения и OID справочников ФНСИ; значение определяется контекстом |
| OID организации | Идентификатор юридического лица (МО) в ФРМО. В МИС указывается в поле **Федеральный код МО (OID)** |
| OID подразделения | Идентификатор структурного подразделения в ФРМО. В МИС указывается в поле **Федеральный код подразделения МО (OID)** и не совпадает с OID организации |
| OID справочника | Полный идентификатор справочника ФНСИ, например `1.2.643.5.1.13.13.11.1520` — справочник видов СЭМД |
| Код вида СЭМД | Числовой идентификатор записи в справочнике ФНСИ `1.2.643.5.1.13.13.11.1520`, например 233. В таблицах руководства и в каталоге видов СЭМД он подписан как «OID», но полным OID не является |
| Идентификатор типа СЭМД | Отдельный идентификатор, приведённый для эпикризов ИЭМК в разделе [«Структурированный ЭМД»](./semd/index.mdx#сэмд-для-регистрации-в-иэмк), например `991010000010468`. Не совпадает с кодом вида СЭМД |
| ИПС | Подсистема интеграции прикладных систем ЕГИСЗ |
| ЦБД | Центральная база данных |
| МО | Медицинская организация |
| МИС | Медицинская информационная система |
| СДС | ООО «Смарт Дельта Системс» |
| ЭЦП | Наименование электронной подписи в интерфейсе МИС |
| Протокол ИБ | Протокол истории болезни в МИС |
