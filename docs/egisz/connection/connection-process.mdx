# Порядок подключения

Работу по подключению распределите по этапам. Для каждого юридического лица указывается OID, подключаемые сервисы и перечень видов СЭМД.

## Организационный этап

| Этап | Исполнитель | Действие и результат |
|---|---|---|
| Организационная подготовка | МО, коммерческий отдел СДС | Договор на портал согласован; формы заявок доступны |
| Регистрация юридических лиц и сотрудников | МО | Юридические лица и подразделения зарегистрированы в ФРМО, сведения о медицинских работниках внесены в ФРМР |
| Заявки на подключение | МО | На каждое юридическое лицо подготовлены отдельные заявки на ИЭМК и РЭМД по формам Минздрава России |
| Передача заявок | МО, СДС | Заявки подписаны, сканы и файлы переданы для направления в СТП ЕГИСЗ |
| Подтверждение подключения | Коммерческий отдел СДС | Получено подтверждение подключения каждого заявленного сервиса |
| Определение перечня СЭМД | МО | Определены виды СЭМД для передачи в РЭМД и соответствующие им типы протоколов ИБ, применяемые в медицинской организации. Для передачи в ИЭМК выбраны лицензируемые эпикризы 233 и 235, если они нужны МО |

Перечень видов СЭМД и соответствующих протоколов ИБ определяется по фактически оказываемым услугам.

## Технические требования

До начала настройки выполните [требования для интеграции](./technical-requirements.mdx) по каждому юридическому лицу и согласуйте доступы на период настройки.

## Настройка и тестирование

| Этап | Исполнитель | Действие и результат |
|---|---|---|
| Настройка | СДС, МО | Заполнены реквизиты, настроены ИЭМК, РЭМД, НСИ и служба репликации; выполнена [проверка готовности](/trunk/egisz/diagnostics/check-list) |
| Тестирование | СДС, МО | Выполнена [тестовая отправка СЭМД](./test-integration.mdx) каждого подключённого вида; результаты зафиксированы |
| Эксплуатация | МО | Начато штатное оформление и подписание документов, назначены ответственные за контроль и поддержку |

### Несколько юридических лиц в одной базе МИС

Если в одной базе МИС работают несколько юридических лиц, интеграция каждого из них с ЕГИСЗ настраивается независимо с использованием собственного OID из ФРМО. Связь врача с юридическим лицом определяется его местом работы по ФРМР. В МИС работа ведётся в соответствии с настройками юридических лиц и подразделений, чтобы документ формировался и отправлялся от имени организации, в которой врач фактически провёл приём. Для настройки используйте сведения о [юридическом лице](../settings/organization.mdx), [подразделениях](../settings/departments.mdx) и [сотрудниках](../settings/employees.mdx).
