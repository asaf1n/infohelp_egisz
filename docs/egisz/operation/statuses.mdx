# Статусы обмена

Для РЭМД откройте **Журналы → Протоколы ИБ**, колонку **Статус отправки**. Коды относятся к `fir_emd_arc.status`.

| Код | Наименование | Значение |
|---|---|---|
| 0 | Подготовлен | Протокол подписан; документ ожидает обработки |
| 1 | Сформирован запрос | Документ подготовлен к передаче |
| 2 | Получен синхронный ответ | Шлюз принял запрос; асинхронная проверка ещё ожидается |
| 3 | Ошибка внутреннего контроля | Проверка при формировании не пройдена; передача не выполнялась |
| 4 | Успешный асинхронный ответ | Документ зарегистрирован в РЭМД; присвоен регистрационный номер |
| 5 | Ошибка в асинхронном ответе | Проверки на стороне ЕГИСЗ не пройдены; требуется разбор ошибки |

При кодах 3 и 5 прочитайте текст причины в журнале и перейдите к [диагностике](/trunk/egisz/diagnostics).

## Контроль ИЭМК

В журнале протоколов ИБ проверьте колонки **Дата размещения СЭМД на фед. портале** и **Причина неразмещения во внеш. ИС**. Для ИЭМК используются отдельные результаты передачи; коды таблицы относятся к РЭМД.

## Время ожидания

Если документ остаётся в статусе 2, зафиксируйте время последнего изменения и масштаб проблемы. Проверьте поступление callback в журнале передачи и соответствие адресов [параметрам интеграции](../settings/integration-parameters.mdx). Срок реакции на обращение определяется условиями сопровождения МО.
