# Эксплуатация

Ответственный сотрудник МО контролирует результаты обмена и актуальность сведений, используемых при формировании документов.

1. Проверьте [статусы обмена](./statuses.mdx) для РЭМД и ИЭМК.
2. При ошибке определите затронутые документы и выполните [диагностику](/trunk/egisz/diagnostics).
3. При изменении реквизитов МО и подразделений сверяйте данные с ФРМО; при изменении места работы и должности сотрудников сверяйте данные с ФРМР.
4. Контролируйте сроки действия сертификатов УКЭП и загрузку [НСИ](../settings/nsi.mdx).
5. Если причина ошибки не установлена, подготовьте [обращение в поддержку](/trunk/egisz/diagnostics/support-request) с результатами выполненных проверок.

После изменения реквизитов, настроек, инфраструктуры или версии МИС повторите относящиеся к изменению проверки из раздела [«Диагностика»](/trunk/egisz/diagnostics).
