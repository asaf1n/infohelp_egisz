# Вопросы и ответы

## Документ получил синхронный ответ. Он зарегистрирован?

Для РЭМД синхронный ответ подтверждает приём запроса шлюзом. Регистрацию подтверждают успешный асинхронный ответ и регистрационный номер. Проверьте [статус передачи](./statuses.mdx).

## SQL-скрипт проверки конфигурации не выявил ошибок. Можно начинать работу?

Запрос из [SQL-скрипта проверки конфигурации](/trunk/egisz/diagnostics/sql-configuration-check) проверяет часть настроек и может не вернуть строки для отсутствующих сущностей. Выполните остальные пункты [чек-листа проверки готовности](/trunk/egisz/diagnostics/check-list) и [тестовую отправку СЭМД](../connection/test-integration.mdx).

## Справочник загружен, но значения в МИС нет. Что проверить?

Проверьте целевую БД, загруженную версию, результат обработки и поле МИС. Для филиальной сети дополнительно проверьте распространение данных из ЦБД. Используйте [инструкцию диагностики НСИ](../../sync_manager/check.mdx#downloaded-not-visible).

## Можно ли переотправить документ после ошибки?

Сначала установите причину и результат предыдущей регистрации. Возможность переотправки зависит от состояния документа; порядок действий приведён в [разделе «Переотправка документов»](/trunk/egisz/operation/resend).

## Как получить доступ к веб-интерфейсу РЭМД?

Доступ предоставляется по заявке в службу технической поддержки ЕГИСЗ. Авторизация выполняется через ЕСИА.

## Что делать, если документ уже зарегистрирован?

Зарегистрированный документ сохраняется в РЭМД в неизменном виде. Для исправления сведений в медицинской организации создайте новый протокол и передайте его как отдельный документ.

## Принимает ли РЭМД документы по анонимным пациентам?

РЭМД не принимает документы без обязательных персональных сведений о пациенте. Состав обязательных сведений определяется руководством по реализации вида СЭМД.

## Можно ли подписывать документы УКЭП на основании машиночитаемой доверенности?

На текущий момент регистрация документов с такой подписью не выполняется.
