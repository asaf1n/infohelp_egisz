# Филиальная сеть

В этой инструкции филиал означает филиальную базу данных МИС. Настройки проверяют на центральной базе данных и на каждой филиальной базе, в которой подписываются документы. Скрипты настройки базы данных также выполняют на всех базах данных филиалов.

1. Укажите временную зону и БД подписанных протоколов по [инструкции параметров интеграции](./integration-parameters.mdx).
2. Загрузите НСИ на центральной базе данных, затем проверьте [доступность значений в целевых филиалах](../../sync_manager/check.mdx).
3. Сверьте задачи распространения данных с [перечнем задач ЕГИСЗ](./replication.mdx) и выполните [проверку репликатора](../../services1/replic/check.mdx).

Для филиальной сети настроена передача журналов `FIR_EMD_ARC` и `FIR_MC_ARC` между ЦБД и филиальными базами. НСИ загружается на ЦБД. Применённую конфигурацию проверьте при [тестовой отправке СЭМД](../connection/test-integration.mdx).

В репликацию из центральной базы данных в филиалы включают таблицы справочников `SYNC_REFERENCE`, `SYNC_REFVERSIONS`, `NSI_DIAGRESEARCH`, `WORKPLACEDOCDET` и `FILIAL_BASE`.
