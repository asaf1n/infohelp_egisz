# Подразделения и медпрофили

## Подразделения

Настройку выполняет сотрудник МО для каждого финподразделения, в котором создаются приёмы.

1. Откройте **Справочники → Структура организации → Финподразделения, кассы, реквизиты клиники, настройки**.
2. Выберите финподразделение.
3. Откройте [НСИ ФРМО](https://nsi.rosminzdrav.ru/dictionaries) и найдите справочник структурных подразделений, затем структурное подразделение, относящееся к настраиваемому юридическому лицу.
4. Заполните **Федеральный код подразделения МО (OID)** и **Федеральное наименование подразделения МО** значениями из найденной записи.
5. Сохраните изменения и проверьте соответствие юридическому лицу.

## Медпрофили

Откройте **Справочники → Структура организации → Медпрофили → Общие** и проверьте поля **Медицинская специальность медпрофиля** и **Профиль медицинской помощи по ФедНСИ**. Путь к форме и названия полей сверьте с интерфейсом используемой версии МИС. Дополнительные сведения о модулях приведены в [справке по модулям](https://help.infoclinica.ru/trunk/modules_descrip/).
