# Настройка РЭМД

Назначение подсистемы описано в разделе [«РЭМД и ИЭМК»](../remd-iemk.mdx).

## Подготовка базы данных

Скрипт выполняйте на базе данных, в которой подписываются протоколы. После создания триггеров перезапустите МИС:

```sql
execute procedure FIR_EMD_REMD_CREATE_TRIGGERS;
```

Для регистрации баз интеграции добавьте сервисные записи в `filial_base`. В запросах укажите фактические адреса баз данных, IP-адрес сервера и идентификатор филиала:

```sql
insert into filial_base (filbaseid, basetype, dbpath, dbipaddr, filial, grpid)
values (GEN_ID(FILIAL_BASE_GEN,1), 1, 'полный адрес БД', 'IP-адрес сервера БД', 1002, 9924);

insert into filial_base (filbaseid, basetype, dbpath, dbipaddr, bdate, filial, grpid)
values (GEN_ID(FILIAL_BASE_GEN,1), 2, 'полный адрес медиа-БД', 'IP-адрес сервера БД', '01.01.1900', 1001, 9924);
```

Для филиальной сети записи о центральной базе и медиа-базе должны соответствовать фактической схеме обмена. После настройки проверьте их наличие SQL-скриптом проверки конфигурации.

## Формирование документов

Подготовьте [параметры интеграции](./integration-parameters.mdx), медиа-базы и [НСИ](./nsi.mdx). Для каждого подключаемого вида и редакции настройте формирование, подписание и передачу по [инструкции подключения СЭМД](../semd/connection.mdx). Состав обязательных данных определяется видом и редакцией документа.

## Передача документов

Для обмена используются следующие задачи службы репликации:

| Задача | Назначение |
|---|---|
| `remd_log_process` | Подготовка подписанных документов |
| `remd_send` | Передача сообщений на регистрацию |
| `remd_in` | Приём результатов регистрации и запросов документов через callback на порт 9945 |
| `remd_error` | Повторная обработка документов с временными ошибками |
| `remd_sprav` | Репликация `FIR_EMD_ARC` из ЦБД в филиалы |

Группа задач и назначение каждой задачи приведены в [перечне задач репликации](./replication.mdx). Расписание и зависимости задач сверьте с эталонной конфигурацией используемой версии МИС по разделу [«Проверка настроек»](../../services1/replic/configuration.mdx#проверка-настроек).

## Проверка результата

При [тестовой отправке СЭМД](../connection/test-integration.mdx) проверьте формирование документа, его подписание, передачу сообщения и ответ ИПС. Для РЭМД зафиксируйте успешный асинхронный результат и регистрационный номер документа.
