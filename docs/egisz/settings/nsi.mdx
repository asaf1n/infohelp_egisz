# Справочники НСИ

Состав справочников определяется руководствами по реализации подключаемых видов СЭМД.

1. Определите перечень подключаемых видов СЭМД и редакций.
2. Для каждого вида сверьте перечень требуемых справочников с его руководством по реализации.
3. Выберите [готовый профиль интеграции для вида и редакции СЭМД](../semd/profiles.mdx) либо согласованный список кодов. Для SyncServer задайте состав в `syncrefcode` или `syncprofiles` файла `sync.conf`; параметры службы и подключение через `infodent.ini` описаны в [автоматической синхронизации](../../sync_manager/automation.mdx). Для филиальной сети загрузку выполняют на центральной базе данных.
4. Выполните [загрузку и обработку справочников](../../sync_manager/synchronization.mdx) выбранным способом.
5. Проведите [проверку службы синхронизации и НСИ](../../sync_manager/check.mdx), включая доступность значений в МИС и целевых филиалах.

Полноту выбранного профиля сверьте с требованиями вида и редакции СЭМД. Общие настройки источников, справочников и профилей приведены в разделе [«Менеджер Загрузок»](../../sync_manager/index.mdx).

## Сопоставление с ФНСИ

Сопоставление данных МИС с федеральными справочниками, участвующими в формировании СЭМД, выполняется через интерфейс справочника в МИС или через таблицы [`DICINFODET`](https://corp.sdsys.ru/trac/sds/wiki/%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B1%D0%B0%D0%B7%D1%8B%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85/%D0%A2%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%8B/DICINFODET) и [`DICINFO`](https://corp.sdsys.ru/trac/sds/wiki/%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B1%D0%B0%D0%B7%D1%8B%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85/%D0%A2%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%8B/DICINFO). Обрабатываемые справочники см. в [таблице справочников ФНСИ](https://corp.sdsys.ru/trac/sds/wiki/%D0%A0%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B0/%D0%94%D0%BE%D0%BA%D1%83%D0%BC%D0%B5%D0%BD%D1%82%D0%B0%D1%86%D0%B8%D1%8F/%D0%A1%D0%AD%D0%9C%D0%94/%D0%A4%D0%9D%D0%A1%D0%98).

### Типы документов

Для типов документов ([справочник CLDOCTYPE](https://corp.sdsys.ru/trac/sds/wiki/%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B1%D0%B0%D0%B7%D1%8B%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85/%D0%A2%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%8B/CLDOCTYPE)) сопоставление проставляется в соответствии со справочником ФНСИ [`1.2.643.5.1.13.13.99.2.48`](https://nsi.rosminzdrav.ru/#!/refbook/1.2.643.5.1.13.13.99.2.48/version/7.2).

1. Обработайте соответствующий справочник из таблицы справочников ФНСИ. Право доступа для открытия справочника: **Справочники → Системные справочники → Справочник типов документов**.
2. В **Справочники → Общие → Типы документов** в столбце **Тип по ФНСИ** выберите соответствующее значение из выпадающего списка.
3. Сохраните изменения.

### Источники финансирования

Для справочника источников финансирования ([`FINSOURCE`](https://corp.sdsys.ru/trac/sds/wiki/%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B1%D0%B0%D0%B7%D1%8B%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85/%D0%A2%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%8B/FINSOURCE)) сопоставление проставляется в соответствии со справочником ФНСИ [`1.2.643.5.1.13.13.11.1039`](https://nsi.rosminzdrav.ru/#!/refbook/1.2.643.5.1.13.13.11.1039/version/5.2).

1. Обработайте соответствующий справочник из таблицы справочников ФНСИ. Право доступа для открытия справочника: **Справочники → Финансовые → Источники финансирования**.
2. В **Справочники → Финансовые → Источники финансирования** в столбце **Вид по ФНСИ** выберите соответствующее значение из выпадающего списка.
3. Сохраните изменения.

### Категории регистрации и источники финансирования

Категории из карточки регистрации ([`CLGROUP`](https://corp.sdsys.ru/trac/sds/wiki/%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B1%D0%B0%D0%B7%D1%8B%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85/%D0%A2%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%8B/CLGROUP)) сопоставляются со справочником источников финансирования (`FINSOURCE`): в поле `CLGROUP.FINSOURCE` указывается значение из `FINSOURCE.FINID`.

:::warning
Если приём пациента оформлен по договору с клиникой, проверьте, что наименование договора равно «Договор на оказание платных медицинских услуг».
:::

Для справочника **Типы договоров** (**Организации → Справочник юридических лиц**, путь **Сервис → Справочники → Типы договоров**) установите отметку **Договор ОМС** напротив категории «ОМС» — это необходимо для корректного определения полиса пациента.

### Услуги

В **Справочники → Прейскурант → Реквизиты** заполняются «Код Минздрава» и «Наименование Минздрава» по ФНСИ [`1.2.643.5.1.13.13.11.1070`](https://nsi.rosminzdrav.ru/#!/refbook/1.2.643.5.1.13.13.11.1070/version/2.10). Состав необходимых сопоставлений зависит от вида СЭМД.

### Единицы измерения

Для справочника единиц измерения ([`EDIZM`](https://corp.sdsys.ru/trac/sds/wiki/%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B1%D0%B0%D0%B7%D1%8B%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85/%D0%A2%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%8B/EDIZM)) сопоставление проставляется в соответствии со справочником ФНСИ [`1.2.643.5.1.13.13.11.1358`](https://nsi.rosminzdrav.ru/#!/refbook/1.2.643.5.1.13.13.11.1358/version/3.21).

Обработайте соответствующий справочник из таблицы справочников ФНСИ и укажите значение уникального идентификатора справочника в поле `EDIZM.FLSI_CODE`. Значения, не сопоставленные автоматически, сопоставьте вручную.

### Биоматериалы

Для справочника биоматериалов ([`TOOTHNAM`](https://corp.sdsys.ru/trac/sds/wiki/%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B1%D0%B0%D0%B7%D1%8B%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85/%D0%A2%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%8B/TOOTHNAM)) сопоставление проставляется в соответствии со справочником ФНСИ [`1.2.643.5.1.13.13.11.1081`](https://nsi.rosminzdrav.ru/#!/refbook/1.2.643.5.1.13.13.11.1081/version/3.3).

Обработайте соответствующий справочник из таблицы справочников ФНСИ и укажите значение кода справочника в поле `TOOTHNAM.FLSI_CODE`.

### Социальные статусы

Для справочника социальных статусов ([`STAT_SOC_STATUS`](https://corp.sdsys.ru/trac/sds/wiki/%D0%A1%D1%82%D1%80%D1%83%D0%BA%D1%82%D1%83%D1%80%D0%B0%20%D0%B1%D0%B0%D0%B7%D1%8B%20%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85/%D0%A2%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%8B/STAT_SOC_STATUS)) сопоставление проставляется в соответствии со справочником ФНСИ [`1.2.643.5.1.13.13.11.1038`](https://nsi.rosminzdrav.ru/dictionaries/1.2.643.5.1.13.13.11.1038/passport/17.2).

1. Обработайте соответствующий справочник из таблицы справочников ФНСИ.
2. В **Справочники → Общие → Социальные статусы** в правой части, в строке **Вид по ФНСИ**, выберите соответствующее значение из выпадающего списка.
3. Выйдите из справочника — изменения сохранятся автоматически.
