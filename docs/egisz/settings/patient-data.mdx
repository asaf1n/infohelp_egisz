# Данные пациентов

Перед формированием СЭМД проверьте сведения пациента в разделе **Картотека пациентов → Карточка регистрации**. Состав обязательных сведений зависит от вида и редакции СЭМД, поэтому сверяйте его с руководством по реализации выбранного вида документа до [тестовой отправки СЭМД](../connection/test-integration.mdx).

В карточке проверьте следующие сведения, которые используются при формировании документов:

- ФИО;
- дата рождения;
- документ, удостоверяющий личность;
- СНИЛС.

Для отдельных видов документов действуют условия, при которых СНИЛС может не указываться, например в зависимости от возраста пациента или при иностранном документе, удостоверяющем личность. Если регистрация отклонена из-за отсутствия СНИЛС, проверьте эти условия по описанию ошибки `NO_SNILS` в [каталоге ошибок](../diagnostics/error-catalog.mdx#этап-1-проверка-запроса-на-регистрацию).

Отметку об отказе от передачи данных указывайте в случаях, предусмотренных внутренним порядком медицинской организации. Порядок работы с таким отказом описан в разделе [«Отказ пациента»](../operation/patient-refusal.mdx).
