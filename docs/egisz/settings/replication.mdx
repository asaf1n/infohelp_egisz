# Задачи репликации ЕГИСЗ

Обмен с ИЭМК и РЭМД выполняют группы задач `iemk` и `remd`. Порядок запуска, расписание и зависимости задач сверьте с эталонной конфигурацией используемой версии МИС по разделу [«Проверка настроек»](../../services1/replic/configuration.mdx#проверка-настроек).

Если база конфигурации клиники создана на основании эталонной, справочник таблиц репликации актуализируйте по процедуре [обновления на основании эталонной базы replconf](../../services1/replic/configuration.mdx#обновление-справочника-таблиц-по-эталонной-базе-replconf).

## ИЭМК

| Задача | Описание |
|---|---|
| `iemk` | Группа задач |
| `iemk_out` | Передача сведений о пациенте и случае |
| `iemk_in` | Приём ответов ИПС, порт 9921 |
| `iemk_handler` | Обработка ответов и обновление статусов |
| `iemk_oper` | Репликация FIR_MC_ARC из филиалов в ЦБД |
| `iemk_sprav` | Репликация FIR_MC_ARC из ЦБД в филиалы |

## РЭМД

| Задача | Описание |
|---|---|
| `remd` | Группа задач |
| `remd_log_process` | Подготовка подписанных документов |
| `remd_send` | Передача сообщений на регистрацию |
| `remd_in` | Результаты регистрации и запросы документов, порт 9945 |
| `remd_error` | Повторная обработка документов с временными ошибками |
| `remd_sprav` | Репликация FIR_EMD_ARC из ЦБД в филиалы |

## Проверка результата

Выполните [проверку работы репликатора](../../services1/replic/check.mdx): состояние службы, доступность консоли и результаты нужных задач. Общие настройки приведены в разделе [«Система репликации»](../../services1/replic/index.mdx).

Затем при [тестовой отправке СЭМД](../connection/test-integration.mdx) проверьте соответствие callback-адресов [параметрам интеграции](./integration-parameters.mdx), поступление ответа и изменение статуса.

:::note Условия запуска задач
Перед запуском сверьте параметры задач с эталонной базой replconf. Для `remd_error` актуализируйте скрипт списка ошибок автоматической переотправки.
:::
