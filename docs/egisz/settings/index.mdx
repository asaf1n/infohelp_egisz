# Настройка интеграции

Реквизиты заполняют сотрудники медицинской организации. Параметры обмена и инфраструктуру настраивают специалисты, которым предоставлены соответствующие права.

1. Заполните [реквизиты юридического лица](./organization.mdx), [подразделений](./departments.mdx) и [сотрудников](./employees.mdx). Проверьте [данные пациентов](./patient-data.mdx), используемые в документах.
2. Проверьте [параметры интеграции](./integration-parameters.mdx), медиа-базы и часовые пояса.
3. Подготовьте [справочники НСИ](./nsi.mdx).
4. Выполните настройку контуров [ИЭМК](./iemk.mdx) и [РЭМД](./remd.mdx) с учётом подключаемых видов СЭМД.
5. Проверьте [задачи службы репликации](./replication.mdx). Для филиальной сети учтите особенности, описанные на странице [«Филиальная сеть»](./filials.mdx).
6. Выполните [проверку готовности](/trunk/egisz/diagnostics/check-list).

Для настройки ИЭМК и РЭМД используйте инструкции этого раздела и эталонную конфигурацию той же версии МИС.

Общие действия с компонентами описаны в [«Служебные модули»](../../services1/index.mdx): [обновление МИС](../../services1/cp-upgrader/index.mdx), [репликация](../../services1/replic/index.mdx), [синхронизация справочников](../../sync_manager/index.mdx). Описания модулей МИС доступны в [справке по модулям](https://help.infoclinica.ru/trunk/modules_descrip/).
