# Параметры интеграции

Откройте **Сервис → Настройки → Интеграция**. Сохраните значения для выбранного тестового или промышленного подключения.

<IntegrationParameters />

Идентификатор клиники берётся из поля «Адрес сервиса данных» в настройках виртуального сайта портала. Замените текст в квадратных скобках идентификатором вашей клиники перед сохранением.

## Медиа-база и часовой пояс

В **Справочники → Структура организации → Филиалы** проверьте временную зону по UTC. На вкладке **Реквизиты** задайте **БД подписанных протоколов (медиа-база)** для каждого филиала и центральной базы данных.

## Случаи заболевания

Сведения о случае передаются в составе СЭМД, которые их предусматривают (см. [«РЭМД и ИЭМК»](../remd-iemk.mdx)), и формируются в МИС через учёт случаев заболевания. Настройте доступ к этой функции для сотрудников, подписывающих протокол:

1. В правах доступа сотрудника откройте **Приём → Случаи заболевания. Диагноз**.
2. Включите **Учёт случаев заболевания** и **Постановку основного диагноза через учёт случаев заболевания**.
3. Для стоматологических клиник дополнительно откройте **Сервис → Настройки → Поликлиника → Общие** и включите **Учёт случаев заболевания в стоматологии**.

Медицинские организации, ведущие учёт случаев в упрощённом режиме, используют автоматическое закрытие случая. Открытие случая происходит при установке диагноза в приёме.

Настройка формирования эпикризов выполняется в **Сервис → Настройки → Поликлиника → История болезни → Процессный ввод случая заболевания → Формирование эпикриза**. Для ручного формирования и подписания откройте **Журналы → Случаи заболеваний**.

## Доверенное подключение между базами данных

Для обращения к филиальным базам настройте доверенное подключение под текущим пользователем без пароля. Правило мэппинга создайте в BkUtils на всех базах данных, включая медиабазы и базу конфигуратора репликатора.

```sql
CREATE OR ALTER MAPPING ESOE_CLUSTER_AUTH
  USING PLUGIN CLUSTER
  FROM USER CHEA to USER CHEA;
```

Проверьте подключение к текущей базе данных в BkUtils под пользователем CHEA. Проверка пройдена, если команда выполняется без ошибки.

```sql
execute block
as
declare tmp integer;
begin
  execute statement 'select 1 from rdb$database'
  on external 'localhost:' || rdb$get_context('SYSTEM', 'DB_NAME') as user current_user role current_role password ''
  into tmp;
end
```
