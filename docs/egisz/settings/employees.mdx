# Сотрудники

Подготовьте сведения о месте работы и должности врача в ФРМР, а также действующий сертификат его УКЭП.

1. Откройте **Справочники → Справочник персонала** и выберите сотрудника.
2. Проверьте связь карточки с физическим лицом, актуальные ФИО и СНИЛС.
3. В поле **Должность (справочник)** выберите значение, соответствующее должности в ФРМР.
4. Заполните **Специальность в отделении** из списка специализаций медпрофиля и укажите период действия.
5. Проверьте наличие действующего сертификата УКЭП. Настройку ЭЦП выполняйте в модуле [«Электронная подпись»](https://help.infoclinica.ru/trunk/electro_sign/).
6. Сохраните значения и проверьте данные всех сотрудников, подписывающих документы.

После загрузки справочника «Должности» перечень должностей в справочнике персонала обновляется.
