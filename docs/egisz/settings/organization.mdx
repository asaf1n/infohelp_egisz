# Юридическое лицо (МО)

Настройку выполняет сотрудник МО для каждого юридического лица, участвующего в обмене. Подготовьте реквизиты организации из [НСИ ФРМО](https://nsi.rosminzdrav.ru/dictionaries).

1. Откройте **Справочники → Организации → Реквизиты клиники**.
2. Заполните поля по таблице.
3. Сохраните изменения и повторно откройте карточку, чтобы проверить значения.

| Поле | Что указать |
|---|---|
| ОГРН, ИНН | Реквизиты юридического лица |
| Юридический и фактический адрес | Адреса с выбором по ФИАС |
| Телефон организации | Контактный телефон юридического лица |
| Федеральный код МО (OID) | OID медицинской организации из [НСИ ФРМО](https://nsi.rosminzdrav.ru/dictionaries) |
| Территория | Территория расположения организации |
| Сведения о лицензии | Реквизиты лицензии на медицинскую деятельность |

Для юридического лица и структурного подразделения используются разные OID. Для подразделений используйте страницу [«Подразделения»](./departments.mdx).
