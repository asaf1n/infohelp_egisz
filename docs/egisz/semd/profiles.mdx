# Профили НСИ для СЭМД

Профиль загрузки, настраиваемый в форме **Справочники → Настройка профилей менеджера загрузок**, объединяет справочники для совместной синхронизации. При подключении вида СЭМД выберите соответствующий набор, укажите его код в настройках SyncServer и проверьте результат.

Профиль загрузки и интеграционный профиль, который задают для типа протокола, решают разные задачи. Выбор набора НСИ не подключает формирование документа. Настройка передачи описана в [подключении СЭМД](./connection.mdx).

## Выбрать готовый набор

1. Откройте [менеджер синхронизации](../../sync_manager/synchronization.mdx#запуск-менеджера) для нужной БД.
2. Перейдите в **Справочники → Настройка профилей менеджера загрузок**.
3. Через **Поиск** найдите профиль, например **СЭМД 227 Протокол консультации (CDA) Редакция 5**. Выберите его в левой части формы.
5. Проверьте **Дату отключения профиля**. Набор должен соответствовать используемому виду документа и быть действующим на момент запуска.
6. В таблице просмотрите коды и наименования справочников. Укажите **Идентификатор профиля менеджера загрузок** в sync.conf для настройки службы.

Иллюстрация показывает расположение полей. Состав и код выбранного набора проверяйте в целевой БД.

## Реквизиты профиля

| Поле формы | Назначение при работе с готовым набором |
|---|---|
| **Наименование профиля менеджера загрузок** | Название в списке: код вида и его наименование, например **СЭМД 227 Протокол консультации (CDA) Редакция 5**. Если наименование усечено, полный текст приведён в комментарии |
| **Текстовый идентификатор профиля менеджера загрузок** | Код для `syncprofiles`. Например, `227` для набора **СЭМД 227 Протокол консультации (CDA) Редакция 5**; значение сверьте в целевой БД |
| **Хранимая процедура для получения перечня идентификаторов справочников** | Дополнительный динамический источник состава, если он настроен в профиле |
| **Комментарий** | Вид документа, руководство, редакция и сведения о полноте набора |
| **Дата отключения профиля** | Дата окончания действия профиля |
| Нижняя таблица **Код / Наименование** | Справочники, непосредственно включённые в профиль |

Профили могут образовывать дерево. При выборе родительского профиля SyncServer рекурсивно собирает справочники самого профиля и дочерних профилей, включая результат настроенных процедур и непосредственно включённые справочники. Повторяющиеся справочники исключаются из итогового списка.

Пустое поле процедуры допустимо для готового набора, состав которого перечислен в нижней таблице. Процедура `SYNC_PROFILE_GET_DEFAULT` определяет состав по настройкам протоколов МИС; указывайте её, если требуется такой способ выбора справочников. При вызове без параметров она использует протоколы за последние 30 дней; на шаблонной базе такой результат может быть пустым.

## Подключить наборы к SyncServer

1. В `sync.conf` проверьте `a`: он должен выбирать ту же БД, в которой просмотрены профили. Сверьте [параметры службы](../../sync_manager/reference.mdx#configuration).
2. Укажите в `syncprofiles` сохранённые текстовые коды выбранных наборов через запятую. Например, для существующих наборов с кодами `227` и `228`:

   ```ini
   syncprofiles = 227,228
   ```

3. Сверьте получаемый состав, особенно если выбран родительский профиль. Сервер допускает числовые ID и текстовые идентификаторы; для переноса настройки между БД используйте проверенные текстовые коды. Локальные ID записей между БД могут отличаться.
4. Настройте время выполнения и примените конфигурацию по [инструкции SyncServer](../../sync_manager/automation.mdx#configuration-steps).
5. В журнале проверьте прочитанный список профилей и выполнение конкретных справочников, затем подтвердите загрузку, обработку и доступность значений в МИС.

Если одновременно задан `syncrefcode`, дополнительно проверьте фактический общий состав запуска. Правила совместного применения двух параметров проверьте на установленной версии.

## Загрузить справочники набора вручную

Просмотрите состав выбранного профиля, затем откройте **Справочники → Мастер синхронизации** и отметьте нужные справочники по их OID. Выполните [загрузку и обработку](../../sync_manager/synchronization.mdx).

Для автоматической загрузки набора укажите его код в `syncprofiles`. Ручная процедура использует выбор справочников в мастере; наличие отдельной команды запуска профиля требует проверки для установленной версии.

## Проверить состав и результат

1. Сопоставьте набор с руководством по реализации подключаемой редакции СЭМД. Если требуемого OID нет в наборе, уточните у сопровождения способ использования этого справочника в МИС: он может иметь другую настройку источника или использоваться как системные значения.
2. Проверьте требуемую версию каждого справочника. Наличие OID в профиле не закрепляет версию и не задаёт разрешённое подмножество значений для поля СЭМД.
3. После выполнения проверьте загрузку, обработку и контрольное значение в пользовательской форме. Для филиальной сети повторите контроль в целевом филиале.
4. Если журнал показывает пустой состав, проверьте код, целевую БД, дату отключения, дочерние профили, нижнюю таблицу и результат настроенной процедуры.

Профиль может содержать неполный набор НСИ. Успешная обработка всех его элементов подтверждает выполнение настроенного состава; полноту проверяйте отдельно по требованиям вида и редакции СЭМД. При отклонениях выполните [проверку службы и НСИ](../../sync_manager/check.mdx).
