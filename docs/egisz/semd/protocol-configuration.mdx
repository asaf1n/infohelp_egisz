# Настройка собственного протокола клиники

Для каждого типа протокола, передаваемого в РЭМД, настройте обязательность подписи ЭЦП и интеграционный профиль.

1. Откройте **Настройки → Настройки ИБ** и выберите собственный протокол клиники.

2. В реквизитах протокола установите **Подпись ЭЦП**.

![Признак «Подписывать ЭЦП» в настройках протокола](/img/semd-protocols/protocol-config-3.png)

3. Откройте вкладку **Интеграционные профили**. Нажмите **Добавить** и укажите интеграционный профиль, соответствующий виду СЭМД по ФНСИ `1.2.643.5.1.13.13.11.1520`.

![Выбор вида документа при настройке протокола](/img/semd-protocols/protocol-config-1.png)

4. Сохраните настройки.

## Добавление параметров из эталонного протокола

1. В группе **Параметр** выберите **Добавить из другого протокола**.

![Команда добавления параметров из другого протокола](/img/semd-protocols/protocol-config-4.png)

2. В строке **Протокол-источник** выберите эталонный протокол СЭМД.

![Выбор протокола-источника и параметров для переноса](/img/semd-protocols/protocol-config-2.png)

3. Нажмите **Выделить обязательные**. Жёлтым цветом отмечаются строки, настройки которых совпадают с параметрами протокола МО.
4. Перенесите необходимые параметры или группы параметров.
5. Нажмите **Подтвердить**.

Для добавленных параметров укажите вид, тип и запрос к справочнику так же, как в эталонном протоколе. Удалять можно только параметры, добавленные в протокол МО. Если собственный параметр заменяется параметром эталонного протокола, укажите для него дату окончания действия.

## Проверка результата

Проверьте установленный интеграционный профиль, признак **Подпись ЭЦП** и состав параметров. Затем выполните [тестовую отправку СЭМД](../connection/test-integration.mdx) выбранного вида и редакции.
