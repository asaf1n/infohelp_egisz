# Модуль «Интеграция с ЕГИСЗ»

Руководство помогает подготовить подключение медицинской организации, настроить обмен в МИС «Инфоклиника», проверить передачу и контролировать её результат. Назначение подсистем, границы результатов и критерии их проверки приведены на странице [«РЭМД и ИЭМК»](./remd-iemk.mdx).

![Схема обмена: МИС «Инфоклиника» → портал «Инфоклиника.RU» → ИПС ЕГИСЗ → ИЭМК и РЭМД](/img/integration-scheme.svg)
МИС «Инфоклиника» передаёт сообщения через портал «Инфоклиника.RU» в ИПС ЕГИСЗ. Выбор вида СЭМД, редакции и настройка его передачи описаны в разделе [«СЭМД»](./semd/index.mdx).

## Порядок подготовки к работе

Подготовка к обмену выполняется в следующей последовательности. Разделы «Подключение интеграции», «Настройка», «СЭМД» и «Диагностика» самостоятельны; шаги ниже показывают, в каком порядке к ним обращаться.

1. Ознакомьтесь с этапами и исполнителями в разделе [«Порядок подключения»](./connection/connection-process.mdx).
2. Выполните [требования для интеграции](./connection/technical-requirements.mdx) по каждому юридическому лицу.
3. Заполните реквизиты и настройте обмен по разделу [«Настройка»](./settings/index.mdx).
4. Подключите нужные виды СЭМД по инструкции [«Подключение вида СЭМД»](./semd/connection.mdx).
5. Проверьте готовность по [чек-листу проверки](./diagnostics/check-list.mdx).
6. Выполните [тестовую отправку СЭМД](./connection/test-integration.mdx) и зафиксируйте результаты.
7. После успешной тестовой отправки переходите к [эксплуатации](./operation/index.mdx): контролю статусов и актуализации данных.
