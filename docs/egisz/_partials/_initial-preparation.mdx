Перед началом проверки подготовьте на сервере с установленной МИС файлы обновления из хранилища `sds-programs\trunk\`: `Upgrade.zip`, `Report.zip` и `Reference.zip`.

1. На сервере МИС выполните **Модульное обновление «Федеральные сервисы» → Установка исправлений**.
2. Через **Medreport** синхронизируйте файлы `Report.zip` и `Reference.zip`.
