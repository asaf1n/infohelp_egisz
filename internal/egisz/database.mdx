# База данных (внутреннее)

Начните с [SQL-скрипта проверки конфигурации](/trunk/egisz/diagnostics/sql-configuration-check). Запрос возвращает результаты по отдельным настройкам; учитывайте перечисленные на странице ограничения.

Внутренние запросы для углублённой диагностики и изменения данных в разделе не приведены. Для дальнейшего разбора сохраните идентификатор документа, статус, текст ошибки, журналы и результаты выполненных проверок. Передайте их по [порядку эскалации в разработку](./escalation-to-development.mdx).
