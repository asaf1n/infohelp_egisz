# Проверка конфигурации БД

Начните с [SQL-скрипта проверки конфигурации](/trunk/egisz/diagnostics/sql-configuration-check) и учтите его ограничения.

Дополнительных SQL-запросов для углублённой диагностики на этой странице нет.

Для дальнейшего разбора сохраните идентификатор документа, статус, текст ошибки, журналы и результаты проверок. Передайте их по [порядку эскалации в разработку](./escalation-to-development.mdx).
