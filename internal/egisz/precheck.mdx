# Предварительная проверка (Precheck)

## Назначение

Предварительную проверку выполняют в следующих случаях:

- перед первичной настройкой интеграции;
- перед диагностикой любой ошибки ЕГИСЗ;
- перед передачей обращения на вторую линию (ЛТП).

## Порядок выполнения

Пакеты размещены в каталоге `sds-programs\trunk`. До применения сверьте их с поддерживаемой версией МИС и выполните [подготовку к обновлению](/trunk/services1/cp-upgrader/).

1. Для **Upgrade.zip** выполните **Модульное обновление → Федеральные сервисы → Установка исправлений**.
2. Синхронизируйте **Report.zip** через Medreport.
3. Синхронизируйте **Reference.zip** через Medreport.
4. Проверьте, что используется поддерживаемая версия МИС, и сохраните результат обновления.

По анкете подключения сверьте версию МИС, настройки OID и УКЭП. Для компонентов используйте общие инструкции: [проверка репликатора](/trunk/services1/replic/check), [синхронизация и НСИ](/trunk/sync_manager/check), [результат обновления](/trunk/services1/cp-upgrader/check). При необходимости продолжите [углублённую диагностику](./deep-diagnostics.mdx).

## Проверка результата

Порядок применения пакетов сверьте с используемой версией МИС. После обновления проверьте результат обмена в МИС.
