# Обязательный Precheck

Единственный источник правила обязательной предварительной проверки перед настройкой и диагностикой.

## Назначение

Единственный источник правила обязательного precheck. Выполняется:

- перед первичной настройкой интеграции;
- перед диагностикой любой ошибки ЕГИСЗ;
- перед передачей обращения на вторую линию (ЛТП).

## Порядок выполнения

Каталог `sds-programs\trunk`:

1. **Upgrade.zip** — выполнить: Модульное обновление → Федеральные сервисы → Установка исправлений.
2. **Report.zip** — выполнить синхронизацию через Medreport.
3. **Reference.zip** — выполнить синхронизацию через Medreport.

После выполнения — проверить, что используется поддерживаемая версия МИС.

Дополнительно, по чек-листу диагностики интеграции РЭМД, на основе анкеты подключения проверяются: версия МИС, настройки OID, УКЭП, задачи репликатора — см. [углублённую диагностику](./deep-diagnostics.mdx).
